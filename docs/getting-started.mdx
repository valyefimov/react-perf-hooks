`react-perf-hooks` is a focused toolkit for measuring render frequency, runtime cost, and user-facing performance signals in React applications.

## Installation

```bash
npm install react-perf-hooks
```

Optional peer dependency for `useWebVitals`:

```bash
npm install web-vitals
```

## Setup

Import only the hooks you need. The package is tree-shakeable.

```tsx
import {
  useCLS,
  useComponentLifecycle,
  useDebouncedState,
  useINP,
  useIntersectionObserver,
  useLongTasks,
  useMemoProfiling,
  useMemoryStatus,
  usePerformanceMark,
  useRenderBudget,
  useRenderTracker,
  useThrottledState,
  useWebVitals,
} from 'react-perf-hooks';
```

## Development vs production behavior

- `useRenderTracker`, `useRenderBudget`, `useComponentLifecycle`, `useMemoProfiling`, `useRenderCount`, `useWhyDidYouUpdate`, and `useAllocationTracker` are development-oriented by default.
- Most debug logging is disabled when `NODE_ENV=production`.
- `useRenderTracker` and `useRenderBudget` can be force-enabled in production for temporary diagnostics via their `enabled` options. `useRenderCount`, `useWhyDidYouUpdate`, `useAllocationTracker`, and `useMemoProfiling` are always a noop in production, regardless of their options, so bundlers can fully tree-shake their diagnostic logic.

## Quick start example

```tsx
import { useDebouncedState, useRenderBudget, useRenderTracker } from 'react-perf-hooks';

export function SearchPanel() {
  const [query, setQuery, stats] = useDebouncedState('', 250);

  useRenderTracker({ query }, { name: 'SearchPanel', warnAt: 12 });
  useRenderBudget(16, 'SearchPanel');

  return (
    <section>
      <input value={query} onChange={(event) => setQuery(event.target.value)} />
      <p>Skipped renders: {stats.skippedRenders}</p>
    </section>
  );
}
```
